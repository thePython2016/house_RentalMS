#  House Rental Management System

A web-based **House Rental Management System** designed to manage tenant records, rental payments, and property information efficiently. The system helps landlords and property managers streamline rental operations, improve record keeping, and enhance communication with tenants.

🔗 **Live Demo:** https://house-rental-management-system.onrender.com/


#  Project Overview

This system allows property owners to:
- Manage tenant information
- Track rental payments
- Manage property listings
- Monitor occupancy status
- Improve rental operation efficiency
- Send notifications via SMS and Email


#  Key Features

- 👤 Tenant management system
- 🏘️ Property listing and tracking
- 💰 Rental payment tracking system
- 📊 Admin dashboard for monitoring operations
- 🔐 Secure admin login system
- 📩 Bulk SMS notifications to tenants
- 📧 Email notification system (receipts, reminders, alerts)
- 📱 Responsive and user-friendly interface
